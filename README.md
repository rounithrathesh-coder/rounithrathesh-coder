### 📌 Overview & Mission
Forensic investigators, forensic pathologists, and medical examiners spend days manually parsing dense, unstructured autopsy reports and crime scene documents. **ForenSyncAI** is an intelligent full-stack forensic intelligence dashboard designed to automate this critical workflow:

- 📄 **Automated PDF Parsing:** Ingests raw, multi-page autopsy and forensic examination reports.
- 🧠 **LLM-Powered Data Extraction:** Uses large language models to extract key forensic parameters, trauma indicators, post-mortem findings, and toxicological values.
- 📊 **9 Specialized Analysis Modules:** Cross-correlates evidence, highlights temporal inconsistencies, maps anatomical trauma, and generates structured executive summaries.
- ⚡ **Time-to-Insight:** Compresses forensic document review cycles from days to minutes with high accuracy and explainability.
